# Be_What_You_Is.sid — instrument map

`Be What You Is` by `Timo Taipalus (Abaddon)` (2010 Abaddon)

Generated by `scripts/dev/instrument-map.js` from a VICE register trace.
The instruments below are **observed** — the registers on the frame after each
note onset, grouped by ADSR. Nothing here is read from a disassembly.

## Provenance

The offset math is printed because getting it wrong is the failure mode this tool
is most likely to hit: a two-byte error makes a correct instrument layout look
wrong by exactly one field.

## Per-instrument profile

Modal behaviour over the first 8 frames of each note. The waveform
sequence is what separates instruments a single onset sample cannot: a two-stage
attack, or a drum's noise tick, shows up here and nowhere else.

| ADSR | waveform sequence | pulse travel | gate off @ | freq range | sampled at |
|---|---|---|---|---|---|
| `$0A00` | none -> pulse -> saw -> pulse | 617/note | >7 | $0F83-$DD08 | +1 |
| `$00A0` | tri -> pulse | 412/note | >7 | $1A15-$52BE | +1 |
| `$9040` | tri -> pulse -> tri -> pulse | 1248/note | 3 | $3428-$684E | +1 |

`sampled at` is how many frames after the onset the registers first settled — gate
still on, a real waveform selected, frequency off the restart sentinels. A player with
no hard restart settles at +1; a larger number is that player's restart length, which
is a fact worth having rather than noise to hide. `unsettled` notes never settled
within 4 frames and fall back to +1, and enough of them make the whole
file `unusable` — see the verdict above.

## Filter

`$D415-$D418` is global rather than per voice, so it is reported once for the file;
the per-voice routing bit of `$D417` is the `filtered` column above.

18 distinct filter register states across the trace — the filter is driven.
