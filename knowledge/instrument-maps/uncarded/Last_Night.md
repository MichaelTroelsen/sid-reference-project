# Last_Night.sid — instrument map

`Last Night` by `Johan Samuelson (Stinsen)` (2021 Genesis Project)

Generated by `scripts/dev/instrument-map.js` from a VICE register trace.
The instruments below are **observed** — the registers on the frame after each
note onset, grouped by ADSR. Nothing here is read from a disassembly.

## Provenance

The offset math is printed because getting it wrong is the failure mode this tool
is most likely to hit: a two-byte error makes a correct instrument layout look
wrong by exactly one field.

| field | value |
|---|---|
| file | `Last_Night.sid` |
| size | 2854 bytes |
| PSID `loadAddress` field | $0000 |
| effective load address | $1000 (**embedded** — first two data bytes, skipped) |
| data starts at byte | 126 |
| image spans | $1000-$1AA7 |
| init / play | $1000 / $1003 |
| subtunes traced | 1 (of 1) |
| frames per subtune | 500 |
| onsets found | 96 |

## Reliability of the ADSR key

**`unusable`** — 55 of 96 notes (57%) never reach a settled frame within 4 frames of the onset — the sample is stuck in the player's hard restart, so these are the restart's registers, not any instrument's.

No mapping table follows. ADSR does not identify an instrument in this file, so
any table keyed on it would be an invention.
